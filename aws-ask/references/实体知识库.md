# AWS 云资源实体知识库 (Entity Knowledge Base)

## 文档摘要

本文档定义了 AWS 云资源查询场景下的完整实体知识体系，旨在为自然语言查询（NLQ）中的实体识别、归一化、验证和关系理解提供结构化支持。

## 2. 实体标识符模式库

### 2.1 AWS 资源 ARN 格式

AWS 使用 ARN (Amazon Resource Name) 作为全局唯一标识符：

```
arn:partition:service:region:account-id:resource-type/resource-id
```

| 资源类型 | ARN 示例 | 说明 |
|---------|---------|------|
| EC2 实例 | `arn:aws:ec2:ap-southeast-1:123456789012:instance/i-0123456789abcdef0` | - |
| S3 Bucket | `arn:aws:s3:::my-bucket` | 全局，无区域和账号 |
| IAM 用户 | `arn:aws:iam::123456789012:user/alice` | 无区域 |
| IAM 角色 | `arn:aws:iam::123456789012:role/my-role` | - |
| Lambda 函数 | `arn:aws:lambda:ap-southeast-1:123456789012:function:my-function` | - |
| ELBv2 ALB | `arn:aws:elasticloadbalancing:ap-southeast-1:123456789012:loadbalancer/app/my-alb/xxx` | - |
| RDS 实例 | `arn:aws:rds:ap-southeast-1:123456789012:db:my-db` | - |
| DynamoDB 表 | `arn:aws:dynamodb:ap-southeast-1:123456789012:table/my-table` | - |
| SQS 队列 | `arn:aws:sqs:ap-southeast-1:123456789012:my-queue` | - |
| SNS 主题 | `arn:aws:sns:ap-southeast-1:123456789012:my-topic` | - |
| KMS 密钥 | `arn:aws:kms:ap-southeast-1:123456789012:key/xxx-xxx-xxx` | - |
| CloudWatch 告警 | `arn:aws:cloudwatch:ap-southeast-1:123456789012:alarm:my-alarm` | - |

### 2.3 标识符提取策略

**策略优先级**
1. 精确 ID 匹配：优先匹配标准资源 ID 格式（如 `i-xxx`, `sg-xxx`）
2. ARN 匹配：完整 ARN 路径
3. 名称匹配：在指定服务范围内匹配资源名称（通过 Name 标签）
4. 标签匹配：通过标签键值对定位资源
5. IP/域名匹配：通过网络标识定位
6. 上下文推断：基于会话历史或默认值推断
