# 实体知识库 — 腾讯云资源实体定义

> 本文档定义腾讯云各类资源的实体类型、ID格式、同义词映射及属性说明，用于自然语言查询的实体识别与参数提取。

---

## 实体层级结构

```
腾讯云资源体系
├── 网络层
│   ├── VPC (vpc-xxxxxxxx)
│   │   ├── Subnet (subnet-xxxxxxxx)
│   │   ├── SecurityGroup (sg-xxxxxxxx)
│   │   ├── RouteTable (rtb-xxxxxxxx)
│   │   └── NetworkAcl (acl-xxxxxxxx)
│   ├── EIP (eip-xxxxxxxx)
│   ├── NAT Gateway (nat-xxxxxxxx)
│   └── CLB (lb-xxxxxxxx)
│       ├── Listener (lbl-xxxxxxxx)
│       └── Rule / Target
├── 计算层
│   ├── CVM (ins-xxxxxxxx)
│   │   ├── CBS SystemDisk (disk-xxxxxxxx)
│   │   └── CBS DataDisk (disk-xxxxxxxx)
│   ├── Lighthouse (lhins-xxxxxxxx)
│   └── SCF Function (FunctionName+Namespace)
├── 容器/大数据层
│   ├── TKE Cluster (cls-xxxxxxxx)
│   │   └── NodePool (np-xxxxxxxx)
│   └── EMR Cluster (emr-xxxxxxxx)
├── 数据库层
│   ├── CDB MySQL (cdb-xxxxxxxx)
│   ├── Redis (crs-xxxxxxxx)
│   ├── MongoDB (cmgo-xxxxxxxx)
│   └── CDW-Doris (cdwdoris-xxxxxxxx)
├── 存储层
│   ├── COS Bucket (BucketName)
│   ├── CBS Disk (disk-xxxxxxxx)
│   │   └── Snapshot (snap-xxxxxxxx)
│   └── CFS FileSystem (cfs-xxxxxxxx)
├── 消息/流处理层
│   └── CKafka (ckafka-xxxxxxxx)
│       └── Topic / ConsumerGroup
├── 安全/权限层
│   ├── CAM Role (RoleName/RoleId)
│   ├── CAM User (SubUin)
│   └── CAM Policy (PolicyId)
├── 运维/监控层
│   ├── Monitor AlarmPolicy (PolicyId)
│   └── CLS Logset/Topic (UUID)
└── 镜像服务层
    └── TCR (tcr-xxxxxxxx)
        ├── Namespace
        └── Repository / ImageTag
```

## 一、实体类型定义

### 1. CVM 云服务器实例

**实体类型：** `CvmInstance`

**ID 格式：** `ins-[a-z0-9]{8}` （如 `ins-abc12345`）

**同义词映射：**
- CVM、云服务器、虚拟机、ECS（注意：腾讯云叫CVM，不叫ECS）
- 实例、服务器、主机、机器、节点

**核心属性：**

| 属性名 | 重要性 | 说明 | 示例值 |
|--------|--------|------|--------|
| InstanceId | ★★★ | 实例ID | ins-abc12345 |
| InstanceName | ★★★ | 实例名称 | web-server-01 |
| InstanceState | ★★★ | 实例状态 | RUNNING / STOPPED |
| InstanceType | ★★★ | 实例规格 | S5.MEDIUM4 |
| CPU | ★★ | CPU核数 | 4 |
| Memory | ★★ | 内存（GB） | 8 |
| Zone | ★★ | 可用区 | ap-beijing-3 |
| PrivateIpAddresses | ★★★ | 内网IP列表 | ["10.0.0.1"] |
| PublicIpAddresses | ★★ | 公网IP列表 | ["1.2.3.4"] |
| SecurityGroupIds | ★★★ | 安全组ID列表 | ["sg-xxxxxxxx"] |
| OsName | ★ | 操作系统 | CentOS Linux 7.6 |
| ImageId | ★ | 镜像ID | img-xxxxxxxx |
| SystemDisk | ★★ | 系统盘信息 | {DiskType: CLOUD_SSD, DiskSize: 50} |
| DataDisks | ★★ | 数据盘列表 | [{DiskId: disk-xxx, DiskSize: 100}] |
| VirtualPrivateCloud | ★★★ | VPC/子网信息 | {VpcId, SubnetId} |
| ExpiredTime | ★★ | 到期时间 | 2025-12-31 00:00:00 |
| CreatedTime | ★ | 创建时间 | 2024-01-01 00:00:00 |
| Tags | ★★ | 标签列表 | [{Key: env, Value: prod}] |

**状态值说明：**

| 状态值 | 含义 |
|--------|------|
| PENDING | 创建中 |
| RUNNING | 运行中 |
| STOPPED | 已关机 |
| REBOOTING | 重启中 |
| SHUTDOWN | 停止待销毁 |
| TERMINATING | 销毁中 |

**实体类型：** `ClbInstance`

**ID 格式：** `lb-[a-z0-9]{8}` （如 `lb-abc12345`）

**同义词映射：**
- CLB、负载均衡、LB、Load Balancer

| 属性名 | 重要性 | 说明 | 示例值 |
|--------|--------|------|--------|
| LoadBalancerId | ★★★ | 实例ID | lb-abc12345 |
| LoadBalancerName | ★★★ | 实例名称 | prod-lb-01 |
| LoadBalancerType | ★★★ | 类型（OPEN=公网，INTERNAL=内网） | OPEN |
| Forward | ★★ | 负载均衡类型（1=应用型，0=传统型） | 1 |
| LoadBalancerVips | ★★★ | VIP列表 | ["1.2.3.5"] |
| Status | ★★★ | 状态（0=创建中，1=正常运行） | 1 |

| SecureGroups | ★★ | 安全组列表 | ["sg-xxxxxxxx"] |

**监听器实体（ClbListener）：**
- `ListenerId`: `lbl-[a-z0-9]{8}`

**公网 vs 内网 CLB 区分：**

| 特性 | 公网CLB | 内网CLB |
|------|---------|---------|
| LoadBalancerType | OPEN | INTERNAL |
| VIP | 公网IP | VPC内网IP |
| 安全组 | 有（控制入访） | 可选 |
| Monitor Namespace | QCE/LB_PUBLIC | QCE/LB_PRIVATE |
| 查询过滤 | `LoadBalancerType=OPEN` | `LoadBalancerType=INTERNAL` |

**同义词映射：**
- VPC、私有网络、虚拟私有云

```bash
# 查询所有非运行状态的CVM

  --profile devops-readonly \
  --region ap-beijing \
  --Filters '[{"Name":"instance-state","Values":["STOPPED","REBOOTING","SHUTDOWN"]}]'

# 查询所有未绑定的EIP

  --profile devops-readonly \
  --region ap-beijing \

tccli cbs DescribeDisks \
  --profile devops-readonly \
  --region ap-beijing \
  --Filters '[{"Name":"disk-state","Values":["UNATTACHED"]}]'
```

## 五、腾讯云账号信息格式

- **账号ID（AppId）**：纯数字，如 `1250000000`
- **主账号UIN**：纯数字，如 `100000000000`
- **子账号UIN**：纯数字，如 `100000000001`
- **资源六段式**：`qcs::<service>:<account-id>:<resource-type>/<resource-id>`
  - 示例：`qcs::cvm:ap-beijing:uin/100000000000:instance/ins-abc12345`
  - 示例：`qcs::cos:ap-beijing:uid/1250000000:examplebucket-1250000000/*`
- **ARN格式（CAM用）**：`qcs::cam::<account-id>:uin/<uin>`
