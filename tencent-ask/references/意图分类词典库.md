# 意图分类词典库 — 腾讯云查询意图识别

> 本文档定义用于识别用户查询意图的关键词、短语及意图分类规则，帮助将自然语言映射到具体的 tccli 操作。

---

## 一、主意图分类体系

```
查询意图 (6类一级意图)
├── SIMPLE_QUERY        简单查询 — 单服务单操作，直接执行
├── ASSOCIATION_QUERY   关联查询 — 需要跨服务传递ID，多步执行
├── COMPOUND_QUERY      复合查询 — 单服务多条件过滤或跨地域汇总
├── DIAGNOSTIC_QUERY    诊断查询 — 排查故障，需要多步跨服务诊断
├── COMPARE_QUERY       对比查询 — 比较两个资源的差异或历史变化
└── OPS_STATS_QUERY     运维统计 — 资源盘点、成本分析、合规检查
```

---

## 二、一级意图 + 子意图分类

### SIMPLE_QUERY（简单查询）

| 子意图 | 触发词 | 示例 | 复杂度 |
|--------|--------|------|--------|
| SIMPLE_LIST | 列表、有哪些、查询所有、列出 | "查询广州CVM列表" | L1 |
| SIMPLE_DETAIL | 详情、详细、配置、ins-xxx 的 | "查询 ins-abc 的详情" | L1 |
| SIMPLE_STATUS | 状态、是否正常、运行情况 | "cdb-abc 的状态" | L1 |
| SIMPLE_PARAM | 参数、配置项、参数值 | "cdb-abc 的max_connections" | L2 |
| SIMPLE_MONITOR | 监控、指标、CPU/内存/带宽 | "CVM的CPU使用率" | L2 |
| SIMPLE_COUNT | 数量、多少个、统计 | "广州有多少台CVM" | L1 |

### ASSOCIATION_QUERY（关联查询）

| 子意图 | 触发词 | 示例 | 复杂度 |
|--------|--------|------|--------|
| ASSOC_RESOURCE_A_TO_B | 绑定的、关联的、挂载的 | "CVM绑定的安全组" | L2 |
| ASSOC_REVERSE | 反查、哪些xxx属于、哪些xxx绑了 | "安全组绑了哪些CVM" | L2 |
| ASSOC_NETWORK_CHAIN | 网络路径、路由、通不通 | "CVM到外网的路径" | L3 |
| ASSOC_CLB_BACKEND | CLB后端、后端服务器 | "CLB的后端有哪些" | L2 |
| ASSOC_TKE_NODE | TKE节点、集群节点 | "TKE集群的节点列表" | L2 |
| ASSOC_CAM_POLICY | 角色策略、用户权限 | "角色绑定了哪些策略" | L2 |

### COMPOUND_QUERY（复合查询）

| 子意图 | 触发词 | 示例 | 复杂度 |
|--------|--------|------|--------|
| COMPOUND_FILTER | 状态=xxx的、类型=xxx的 | "所有已停止的CVM" | L2 |
| COMPOUND_MULTI_REGION | 所有地域、全部地域、各地域 | "所有地域的CVM数量" | L3 |
| COMPOUND_TAG | 按标签、标签为 env=prod | "env=prod 标签的CVM" | L2 |
| COMPOUND_EXPIRY | 快到期、即将过期、N天内 | "30天内到期的包年包月CVM" | L2 |
| COMPOUND_UNUSED | 未使用、未绑定、空闲 | "未绑定的EIP" | L2 |
| COMPOUND_CROSS_SERVICE | 汇总、同时查多种 | "所有数据库实例清单" | L3 |

### DIAGNOSTIC_QUERY（诊断查询）

| 子意图 | 触发词 | 示例 | 复杂度 |
|--------|--------|------|--------|
| DIAG_NETWORK | 为什么不通、无法访问、网络 | "CVM为什么无法访问外网" | L4 |
| DIAG_CLB_HEALTH | 不健康、健康检查失败 | "CLB后端为什么不健康" | L4 |
| DIAG_DB_CONN | 连接数过高、连不上、连接失败 | "CDB连接数为什么这么高" | L4 |
| DIAG_PERF | 性能慢、高负载、响应慢 | "Redis响应变慢是什么原因" | L4 |
| DIAG_SECURITY | 安全组问题、端口不通 | "为什么80端口不通" | L4 |
| DIAG_TKE | 节点异常、Pod无法调度 | "TKE节点为什么NotReady" | L4 |

### COMPARE_QUERY（对比查询）

| 子意图 | 触发词 | 示例 | 复杂度 |
|--------|--------|------|--------|
| COMPARE_TWO_RES | 对比、比较、和…有什么区别 | "A和B集群的配置有什么不同" | L3 |
| COMPARE_HISTORY | 历史、变化、之前 | "这个参数最近有没有改过" | L3 |

### OPS_STATS_QUERY（运维统计）

| 子意图 | 触发词 | 示例 | 复杂度 |
|--------|--------|------|--------|
| OPS_INVENTORY | 资源盘点、资产清单 | "列出所有地域CVM清单" | L3 |
| OPS_COST | 费用、账单、成本分析 | "上个月各服务费用" | L3 |
| OPS_SECURITY_AUDIT | 安全审计、权限检查 | "哪些安全组允许0.0.0.0/0" | L3 |
| OPS_CAPACITY | 容量、空间、水位 | "Redis内存使用率超80%的实例" | L3 |

## 四、操作动词意图映射

### 查询/列表类（→ Describe/List）

```
查询、查看、列出、获取、显示、展示、看看、查一下、帮我查
有哪些、有什么、多少个、列表、清单、汇总、盘点
```

**示例识别：**
- "查询广州的CVM" → `cvm DescribeInstances --region ap-beijing`
- "有哪些CLB" → `clb DescribeLoadBalancers`
- "列出所有VPC" → `vpc DescribeVpcs`

### 详情类（→ Describe with ID）

```
详情、详细信息、具体信息、配置、属性、参数
ins-xxx 的...、cdb-xxx 的...
```

**示例识别：**
- "查询 ins-abc12345 的详情" → `cvm DescribeInstances --InstanceIds '["ins-abc12345"]'`
- "cdb-abc12345 的参数配置" → `cdb DescribeDBParameters --InstanceId cdb-abc12345`

### 统计/监控类（→ GetMonitorData/Statistics）

```
监控、指标、CPU使用率、内存使用率、带宽、流量、连接数
性能、负载、资源使用、趋势、水位
```

**示例识别：**
- "CVM的CPU使用率" → `monitor GetMonitorData --Namespace QCE/CVM --MetricName CPUUsage`
- "Redis的内存使用情况" → `monitor GetMonitorData --Namespace QCE/REDIS --MetricName MemUsed`

### 诊断/排查类（→ 组合查询）

```
为什么、怎么了、问题、故障、异常、不通、无法访问
排查、诊断、原因、分析、检查、定位
```

**示例识别：**
- "CVM为什么无法访问外网" → DIAGNOSTIC_QUERY，执行多步检查
- "CLB后端为什么不健康" → DIAGNOSTIC_QUERY，检查目标健康状态

### 关联查询类（→ 多步查询）

```
绑定、关联、挂载、属于、对应、相关的
CVM绑定的xxx、xxx对应的CVM
```

**示例识别：**
- "CVM绑定的安全组" → ASSOCIATION_QUERY (CVM → SecurityGroup)
- "CLB绑定的后端服务器" → ASSOCIATION_QUERY (CLB → CVM)
- "VPC下的所有子网" → ASSOCIATION_QUERY (VPC → Subnet)

## 七、时间范围识别

| 用户输入 | 时间范围 | tccli格式 |
|---------|---------|----------|
| 今天、今日 | 当天 00:00:00 ~ 23:59:59 | `YYYY-MM-DD 00:00:00` |
| 昨天 | 前一天 00:00:00 ~ 23:59:59 | `YYYY-MM-DD 00:00:00` |
| 最近1小时 | now-1h ~ now | ISO 8601 |
| 最近3小时 | now-3h ~ now | ISO 8601 |
| 最近24小时 | now-24h ~ now | ISO 8601 |
| 最近7天、近7天 | now-7d ~ now | ISO 8601 |
| 本月 | 当月第1天 ~ 今天 | `YYYY-MM-01` |
| 上月、上个月 | 上月第1天 ~ 最后一天 | `YYYY-MM` |

**时间格式规范：**
- tccli 大多数接口使用 `YYYY-MM-DD HH:MM:SS` 格式
- CDN、Monitor 等接口使用 `YYYY-MM-DDThh:mm:ssZ` (ISO 8601) 格式
- 账单接口使用 `YYYY-MM` (月份) 格式

## 十、复杂度维度评估

| 维度 | L1-简单 | L2-普通 | L3-复杂 | L4-高级 | L5-极复杂 |
|------|---------|---------|---------|---------|----------|
| API调用数 | 1次 | 2-3次 | 4-6次 | 7-10次 | >10次 |
| 是否跨服务 | 否 | 否 | 是 | 是 | 是 |
| 是否跨地域 | 否 | 否 | 可能 | 可能 | 是 |
| 是否需要脚本 | 否 | 否 | 可能 | 是 | 是 |
| 结果数据量 | <10条 | <50条 | <200条 | 大量 | 大量 |
| 需要二次计算 | 否 | 否 | 可能 | 是 | 是 |

## 十一、意图决策树

```
用户输入
├── 包含写操作触发词？
│   └── 是 → 拒绝，返回安全限制提示
├── 包含资源ID？（ins-/cdb-/lb-等）
│   ├── 是 + 包含"绑定/关联/挂载"？→ ASSOCIATION_QUERY
│   ├── 是 + 包含"为什么/诊断/故障"？→ DIAGNOSTIC_QUERY
│   └── 是 → SIMPLE_DETAIL
├── 包含"所有地域/全部/各地域"？
│   └── 是 → COMPOUND_MULTI_REGION（L3，执行多地域循环）
├── 包含状态词（异常/停止/未绑定）？
│   └── 是 → COMPOUND_FILTER（L2，Describe+过滤）
├── 包含"为什么/原因/故障/不通"？
│   └── 是 → DIAGNOSTIC_QUERY（L4，执行多步诊断流程）
├── 包含"绑定的/关联的"但无具体ID？
│   └── 是 → 先澄清资源ID，再执行 ASSOCIATION_QUERY
├── 包含"统计/数量/多少"？
│   └── 是 → COMPOUND_COUNT 或 OPS_STATS_QUERY
└── 默认 → SIMPLE_LIST（单服务Describe）
```

## 十二、场景专项查询词典

### 运维排障场景

| 查询意图 | 关键词 | 对应操作 |
|---------|--------|---------|
| 网络连通性 | 不通、无法连接、网络问题 | EIP+路由表+安全组+ACL多步检查 |

|---------|--------|---------|
| 资源费用 | 费用、账单、花了多少钱 | billing DescribeBillSummaryByProduct |
| 按量 vs 包年包月 | 计费方式、包月比例 | InstanceChargeType 过滤 |
| 到期资源 | 快到期、即将到期 | 过滤 ExpiredTime 字段 |
| 未使用资源 | 空闲、未绑定、浪费 | EIP/CBS UNATTACHED 过滤 |

## 十三、模糊意图消歧策略

### 场景：用户说"查询实例"

```
您好！"实例"可以指多种资源，请问您要查询哪类实例？
1. CVM 云服务器实例（计算资源）
2. CDB MySQL 数据库实例
3. Redis 缓存实例
4. MongoDB 数据库实例
5. TKE 容器集群实例
6. 其他（请描述）
```

### 场景：用户说"查看监控"

```
请问您想查看哪个资源的监控数据？
1. 请提供资源ID（如 ins-xxxxxxxx）
2. 或者描述资源名称/类型和地域
可查看的监控指标：CPU使用率、内存使用率、磁盘IO、网络带宽等
```

### 场景：用户说"有多少资源"

```
您想统计哪类资源的数量？
- 可按服务类型统计（CVM/CDB/Redis等）
- 可按地域统计
- 可按标签统计
请进一步描述您的需求。
```

### 场景：地域不明确

```
您查询的资源属于哪个地域？
常用地域：广州(ap-beijing) / 北京(ap-beijing) / 上海(ap-shanghai) / 成都(ap-chengdu)
如果是所有地域，请说"查询所有地域"。
```
