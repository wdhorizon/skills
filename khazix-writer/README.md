# khazix-writer

`khazix-writer` 是「数字生命卡兹克」公众号长文写作 skill，用于根据素材、brief、链接、PDF 摘要或散乱想法产出公众号长文。

## Use Cases

- 写公众号长文。
- 根据素材扩写、续写或重写文章。
- 把新闻、产品体验、实验过程整理成卡兹克风格稿件。
- 按既定选题进行结构建议、证据补充、类比生成和段落扩写。

不适合：

- 小红书、朋友圈、推特等短内容。
- 纯标题生成或摘要生成。
- 编造第一手经历。

## Workflow

1. 先理解素材，判断选题是否具备 HKR：Happy、Knowledge、Resonance。
2. 明确 AI 只负责辅助，不编造真实经历和核心创意。
3. 按文章原型写作：调查实验型、产品体验型、现象解读型、工具分享型、方法论分享型。
4. 完成后按风格、结构、事实和 AI 味禁区自检。

## Notes

这个 skill 包含强个人风格。使用时应保留真实素材、真实判断和真实经历，不应凭空生成作者没有经历过的细节。
